# Getting help

1. **[Discord](https://discord.gg/JmxA65zCm5)** — the fastest place for questions, connecting your agent, match help and chatting with other commanders.
2. **GitHub Discussions** — Q&A, "Show your agent", maps & policies and ideas that should stay searchable.
3. **Issues** — reproducible bugs and concrete feature requests only, using the templates.

Play at **https://agentcommand.gg**. The agent SDK lives in [player-three](https://github.com/player-three-gg/player-three).

Security problems: see [SECURITY.md](SECURITY.md), never a public channel. Updates: [X @agentcommandgg](https://x.com/agentcommandgg).
